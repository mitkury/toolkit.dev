### Agentic loops and tools
- **Toolkit framework**: Tools are defined with Zod schemas and composed into client/server toolkits; server toolkits contribute functions the model can call.

```39:66:src/toolkits/create-toolkit.ts
export const createServerToolkit = <
  ToolNames extends string,
  Parameters extends ZodRawShape = ZodRawShape,
>(
  toolkitConfig: ToolkitConfig<ToolNames, Parameters>,
  systemPrompt: string,
  toolConfigs: (
    params: z.infer<ZodObject<Parameters>>,
  ) => Promise<Record<ToolNames, ServerToolConfig<any, any>>>,
): ServerToolkit<ToolNames, Parameters> => {
  return {
    systemPrompt,
    tools: async (params: z.infer<ZodObject<Parameters>>) => {
      const tools = await toolConfigs(params);
      return Object.keys(tools).reduce(
        (acc, toolName) => {
          const typedToolName = toolName as ToolNames;
          const baseToolConfig = toolkitConfig.tools[typedToolName];
          const toolConfig = tools[typedToolName];
          acc[typedToolName] = createServerTool(baseToolConfig, toolConfig);
          return acc;
        },
        {} as Record<ToolNames, ServerTool>,
      );
    },
  };
};
```

export async function GET(request: Request) {
  const streamContext = getStreamContext();
  const resumeRequestedAt = new Date();
  // ... validate and locate chat + recent stream id
  const emptyDataStream = createDataStream({ execute: () => { return; } });
  const stream = await streamContext.resumableStream(
    recentStreamId,
    () => emptyDataStream,
  );
  if (!stream) {
    const messages = await api.messages.getMessagesForChat({ chatId });
    const mostRecentMessage = messages.at(-1);
    if (!mostRecentMessage) return new Response(emptyDataStream, { status: 200 });
    if (mostRecentMessage.role !== "assistant") return new Response(emptyDataStream, { status: 200 });
    if (differenceInSeconds(resumeRequestedAt, new Date(mostRecentMessage.createdAt)) > 15) {
      return new Response(emptyDataStream, { status: 200 });
    }
    const restoredStream = createDataStream({
      execute: (buffer) => {
        buffer.writeData({ type: "append-message", message: JSON.stringify(mostRecentMessage) });
      },
    });
    return new Response(restoredStream, { status: 200 });
  }
  return new Response(stream, { status: 200 });
}

### TL;DR
- Uses Vercel AI SDK with OpenRouter provider for all LLM calls; supports streaming, tool-calling, and native model web search.
- Attachments are uploaded to Vercel Blob (base64 in dev), validated, persisted with messages, and rendered in the UI.
- Agentic loops are powered by AI SDK tool-calling; tools are supplied by a typed toolkit framework and can also be exposed over MCP.
- No built-in RAG/vector store; “memory” is provided via the Mem0 toolkit’s semantic search, which the model can call as a tool.
- Search is enabled both natively (for WebSearch-capable models) and via dedicated toolkits (Exa, Notion, GitHub, Google Drive/Calendar, etc.).
